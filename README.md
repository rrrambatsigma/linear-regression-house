## 📌 Project Overview
This project explores whether the size of a house has a significant effect on its selling price.  
Using **Simple Linear Regression**, the goal is to identify and quantify the relationship between house size and price.

The model results show a **strong positive correlation** — as house size increases, the price tends to rise.  
This demonstrates how basic predictive modeling can provide meaningful insights in the housing market.
